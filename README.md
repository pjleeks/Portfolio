## 🧬 Featured Project: Stanford University RNA 3D Folding Inference Pipeline
* **The Challenge:** Engineered a high-throughput sequence alignment and automated inference execution pipeline for deep learning molecular folding models in a strict, zero-internet offline notebook environment.
* **🤖 AI-Assisted Workflows:** Streamlined the reverse-engineering of the offline environment by leveraging generative AI to quickly map complex dependency trees, trace missing directory flags, and write shell-equivalent Python recovery routines.
* **Tech Stack & Libraries:** Python, Parasail, Biopython, NumPy, PyTorch, RDKit, Biotite

### 🛠️ Core Engineering & Implementation
My architectural implementation handles environment configuration, dynamic sequence matching, and model hosting through three dedicated stages:

1. **Accelerated Sequence Alignment Scoring:**
   * Developed dual global/local matching algorithms to evaluate query and target nucleotide string similarities.
   * Implemented custom scoring routines utilizing Biopython's `pairwise2` engine alongside high-performance C-accelerated `parasail` matrix scans (`nw_scan_16` and `sw_scan_16`) to dynamically compute alignment scores normalized by sequence length.

2. **Isolated Environment Auto-Healing:**
   * Fabricated an offline installation routine to compile physics and structural dependencies (`biopython` and `parasail`) using local wheel paths, preventing system conflicts and preserving the container's environment constraints.
   * Created an automated directory recovery process that checks host system paths, verifies source missing flags, and programmatically restores model project source trees (`RNAPro`).

3. **500M Parameter Neural Network Execution:**
   * Managed data-loading handshakes and structural serialization boundaries for running inference on a private 500-million parameter deep learning model checkpoint (`rnapro-private-best-500m.ckpt`) utilizing GPU execution acceleration.
